# Frappe Docs MCP Server

This directory contains the configuration for the `frappe-docs-mcp` server.

## Purpose
Provides LLMs and AI Agents with real-time access to Frappe Framework ORM documentation and live DocType schemas from the `small_erp` database.

## Integration
This allows agents to dynamically understand what fields exist on a "Sales Invoice" or "Leave Request" before attempting to generate Go/Python bridge code.
