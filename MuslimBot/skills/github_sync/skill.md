# GitHub Sync Skill

## Instructions
1. Use the GitHub MCP tool to read the current open issue we are working on.
2. Commit the staged changes using conventional commits.
3. Push the current branch to the remote repository.
4. Use the GitHub MCP tool to open a Pull Request referencing the issue number.
