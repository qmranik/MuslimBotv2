## What I do
- Create remote repositories using `gh repo create`.
- Securely inject environment variables using `gh secret set`.
- Manage commits, pull requests, and git workflows.

## When to use me
Use this skill when initializing the project repository, pushing Docker Compose files, or managing secrets for the stack.
